# Calculator

A simple calculator built with React and [Vite](https://vite.dev).

Live at [highdynamics.github.io/calculator](https://highdynamics.github.io/calculator/).

## Scripts

- `npm start` (or `npm run dev`): runs the app in development at [http://localhost:5173/calculator/](http://localhost:5173/calculator/).
- `npm test`: runs the tests once with [Vitest](https://vitest.dev).
- `npm run build`: builds the app into `dist`.
- `npm run preview`: serves the built app at its production path.
- `npm run deploy`: builds the app and publishes `dist` to the `gh-pages` branch.
